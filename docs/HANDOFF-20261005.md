## 1. 这个工具是什么

独立 CLI + 桌面 GUI，用于**隔离验证 DSH 插件的效果与相互影响**。它**不是**
DSH 桌面版分支，也不修改官方 `app.asar`。

- 官方 runtime：`D:\DeepSeek Harness\resources\runtime\cli\bin\dsh.cmd`（0.2.0-rc.2）
- 每次运行使用独立 `DSH_HOME`；默认跑完即删；真实 `~/.dsh` 只做结构哈希
  前后对比（`real-home-unchanged`）
- 默认不读凭据、不启真实模型；`--mock-model` 用回环 provider 做真实流式回合
- 报告全部中文（`report.html` / `report.md` / `matrix.html` / `matrix.md` / CLI）

## 5. 踩过的坑（都已修，别改回去）

1. **沙箱内 `taskkill` 被拒** → 子进程管道不关、CLI 挂住、端口/temp 残留。
   解决：真启动类命令在沙箱外跑（已写进 README/AGENT-SKILL）。
2. **`ELECTRON_RUN_AS_NODE` 泄漏给孙子进程** → 壳的 Electron 被当作 Node 启动，
   **窗口不显示**。解决：`process-tree.childEnv()` 统一剥离。
3. **MSIX 应用（Codex 桌面版）里 `%LOCALAPPDATA%` 被重定向** →
   GUI 运行时曾建到 `...\Packages\OpenAI.Codex_*\LocalCache\Local\...`，
   桌面快捷方式双击即崩。解决：GUI 运行时默认放**项目内** `gui-runtime/`。
4. **GUI 双击崩溃**：launcher 只认 `DSH_LAB_GUI_CONFIG` 环境变量。
   解决：回退读取 `main.js` 同目录的 `gui-config.json` + 友好错误框。
5. **GUI 自定义按钮 TypeError**：通用点击绑定读了没有 `data-args` 的按钮。
   解决：只绑定 `button[data-args]`；并加 `tests/integration/gui-page.test.js`
   （headless Edge 加载页面、点一遍所有按钮、断言无异常）。
6. **清理 profile 时顺着 pnpm `link:` junction 删除** → 曾两次把
   `fixtures/plugins/session-seeder` 的源文件删掉（已从 git 恢复）。
   解决：`removeTreeSafely()` 用 `lstat` 逐项删除、遇到链接只删链接；
   并加 junction 单测 + e2e「夹具源文件必须存活」断言。
7. **窗口隐藏不合成**：完全隐藏的窗口 `capturePage()` 拍到空白。
   解决：`opacity: 0` + `show: true`；`force-device-scale-factor=1` 保证像素尺寸可比。
   即使 `opacity: 0`，合成器偶尔仍会跳过绘制，让 `capturePage()` 抛
   `UnknownVizError` 或返回陈旧白帧。解决：`captureWindowFrame()` 重试（**不要**
   用 `invalidate()`，它会让 `capturePage()` 挂住），并把
   `capture.unpainted` 写进报告、由 `shell-capture-painted` 断言。
8. **探测时机**：DOM 早采会得到 39/37/39 slot 漂移。
   解决：探测放在会话/设置交互之后；壳探测再叠加 `minSlots`（取 web 基线的
   slot 数）门槛，低于它的“稳定”平台期一律不接受。
9. **headless Edge 每次运行泄漏一整套进程树**：`msedge.exe` 启动器把真实
   browser 交给 broker 后立刻退出，`stopTracked` 看到 `exitCode !== null`
   就跳过了 taskkill；一次 e2e 能留下约 180 个 `msedge` 和 19 个临时目录，
   之后每轮越来越慢、slot/像素结果开始漂移（本次排查中真实踩到）。
   解决：关闭时先发 CDP `Browser.close`，再用 `reapBrowserProcesses()`
   按本次唯一的 `--user-data-dir` 精确回收；单测见
   `tests/unit/browser-reap.test.js`。跑完 e2e 应看到 `msedge` 数量回到基线。
